# Комиссар Вондер: Крушение над Армагеддоном

Браузерный FPS в духе DOOM во вселенной Warhammer 40k, сделанный строго по документам `сценарий.txt`, `механики.txt`, `графика.txt`.

## Стек

- HTML5 + CSS3 + JavaScript ES2022, ES-модули.
- Three.js r160 через CDN jsDelivr (importmap).
- Без сборщиков, npm, бэкенда и внешних ассетов: все модели генерируются процедурно, все звуки синтезируются WebAudio API.
- Единственный внешний ресурс кроме Three.js — шрифт Cinzel (Google Fonts). При отсутствии интернета интерфейс откатывается на Georgia.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | `W` `A` `S` `D` |
| Бег | `Shift` |
| Осмотр | Мышь |
| Огонь из болтера | `ЛКМ` |
| Удар цепным мечом | `ПКМ` |
| Перезарядка | `R` |
| Бросок гранаты | `G` |
| Взаимодействие | `E` |
| Пропуск диалога / кат-сцены | `Пробел` |
| Пауза | `Esc` |
| Переключение оружия | `1` / `2` |

## Настройки

Доступны в главном меню: чувствительность мыши (0.5–2.0), громкость (0–100%). Сохраняются в `localStorage` и применяются на лету.

## Статус фаз

- **Фаза 1 — готова:** каркас проекта, стейт-машина, заставка KrimProduction, главное меню, настройки, WebAudio-синтез, базовый мир (сцена, камера, свет, туман, фон меню), демо-перемещение.
- **Фаза 2 — готова:** 20 процедурных моделей (оружие, руки, граната, три типа орков, деревья, пропсы, обломки «Валькирии», генератор, мешки с песком, ворота, флаг). Все бюджеты полигонов из `графика.txt` выполнены.
- **Фаза 3 — готова:** контроллер игрока (WASD/Shift/мышь, AABB-коллизии, покачивание, HP/броня), болтер с отдачей, магазином и анимацией перезарядки, цепной меч с замахом и «бегущей» цепью, граната с параболой и дружественным огнём, тренировочный полигон, хитмаркер и HUD.
- **Фаза 4 — готова:** базовый `Enemy` (`idle/alert/chase/attack/dead`), `OrkBoy` (60 HP, 15 урона), `OrkShooter` (40 HP, очередь по 3, трассеры, светящийся ствол), `OrkNob` (300 HP, ярость на 50%, ×1.5 размер), обнаружение по видимости и шуму, вздрагивание, падение при смерти и удаление через 5 с.
- **Фаза 5 — готова:** CSM (2 каскада, fade) с fallback на `PCFSoftShadowMap`; SSAO + сдержанный Bloom + `OutputPass` + FXAA; все параметры в `CONFIG.render` (`csm`, `fallbackShadow`, `ssao`, `bloom`); shadow map'ы рендерятся один раз за кадр; честная статистика `renderer.info`; читаемый базовый свет (Ambient/Hemi/экспозиция) и пол на полигоне; URL-флаги `?nocsm`, `?nossao`, `?nobloom`, `?nofxaa`, `?nopost`.
- **Фаза 6 — готова:** `js/dialogue.js` (typewriter, Пробел — досмотр/закрытие), `js/cutscene.js` (ключевые кадры камеры с `easeInOut`, таймлайн событий, тряска, вспышки, затемнение, letterbox), кат-сцены `intro` (~42 с), `wakeup` (~15 с) и `finale` (~30 с). Управление во время кат-сцен отключено, сцена очищается после проигрывания.
- **Фаза 7 — готова:** `js/tutorial.js` — 11 шагов с жёстким гейтингом (движение, обзор, подбор меча/болтера/гранат/патронов, выстрел, перезарядка, удар мечом, граната, первый орк), прогресс-бар HUD, блокировка оружия до подбора, финальный диалог Вондера и переход на полигон.
- **Фаза 8 — готова:** три уровня — `js/levels/level1.js` («Джунгли смерти»), `level2.js` («Орочья выработка»), `level3.js` («Последний рывок»), реестр `levels/index.js`, общий хелпер `levels/common.js` (слияние статики через `mergeGeometries`, AABB-коллайдеры, деревья). Волны врагов, вокс-триггеры, аптечки/патроны/гранаты, карточка уровня, переходы между уровнями и финальная кат-сцена. На третьем уровне — укрепрайон за воротами (бункер, прожекторы, мачта связи) и союзные гвардейцы (`js/allies.js`, `js/models/allies.js`), которые обороняют подступы.
- **Фаза 9 — готова:** чекпоинты в `localStorage` (`wonder.checkpoint.v1`) с сохранением уровня, здоровья, брони, магазина, резерва и гранат; экран смерти с респавном с чекпоинта; финальный экран с «Начать заново»; партиклы [`js/particles.js`](js/particles.js) (кровь при попадании, дым из ствола); вспышки выстрела и маркер выхода.
- **Фаза 10 — готова:** QA-прогон по кодовым путям, `?selftest` (оружие/враги/урон), `?perftest` (draw calls ≤ 200, треугольники ≤ 800k), проверка бюджета в `?debug`, финальная документация и инструкции запуска.

## Аудит моделей

Откройте `http://localhost:8000/audit.html` — страница соберёт все 20 моделей и покажет число мешей, треугольников, минимум по ТЗ и статус. Результат также пишется в консоль как `MODEL_AUDIT`.

Все переходы между режимами выполняются через явную стейт-машину в [`js/main.js`](js/main.js): `splash → menu → cutsceneIntro → cutsceneWakeup → tutorial → playing → paused → dead → cutsceneFinale → ending`.

## Отладка

- `?debug` — FPS, `renderer.info.render.calls`, число треугольников, состояние CSM и постобработки. Счётчики учитывают все проходы кадра (тени, SSAO, сцена).
- `?play` — сразу на первый уровень, минуя заставку, кат-сцены и туториал.
- `?intro` — сразу к вступительной кат-сцене («Валькирия», крушение).
- `?tutorial` — сразу к туториалу (без кат-сцен), удобно проверять гейтинг шагов.
- `?level=level1|level2|level3` — сразу загрузить конкретный уровень.
- `?finale` — сразу к финальной кат-сцене в штабе (для проверки).
- `?nocsm` — принудительный fallback на `PCFSoftShadowMap` без CSM.
- `?nossao` — постобработка без SSAO (Bloom + OutputPass + FXAA остаются).
- `?nobloom` — отключить Bloom.
- `?nofxaa` — отключить FXAA (полезно сравнить края и производительность).
- `?nopost` — полностью прямой рендер без `EffectComposer`.
- `?perftest` — разовый замер draw calls/треугольников с учётом теней и постобработки.
- `?selftest` — автоматическая проверка оружия, врагов и урона с отчётом в консоль.

Флаги комбинируются: например, `?play&nocsm&nossao`.

## Прохождение и QA

Полный поток: «Начать службу» → `cutsceneIntro` → `cutsceneWakeup` → `tutorial` → `level1` («Джунгли смерти») → `level2` («Орочья выработка») → `level3` («Последний рывок») → `cutsceneFinale` → `ending`.

Чек-лист ручной проверки:
- [ ] Меню, настройки и заставка работают; `Esc` ставит игру на паузу.
- [ ] Туториал: 11 шагов с гейтингом, подбор оружия блокирует огонь/удар/гранату до подбора.
- [ ] Уровни: волны врагов по триггерам, вокс-сообщения, аптечки/патроны/гранаты по `E`.
- [ ] Переход между уровнями по `E` в кольце выхода; застрявшие враги не запирают переход (автозачистка за 6 с).
- [ ] Уровень 3: гвардейцы у ворот стреляют по оркам, за воротами бункер/прожекторы/мачта; финальная волна наступает из поля.
- [ ] Смерть: экран «ВЫ ПОГИБЛИ», респавн с чекпоинта возвращает на начало уровня с сохранёнными HP/AP/патронами.
- [ ] Финал: кат-сцена в штабе с бункером, гвардейцами и светом, затем экран «КОНЕЦ ПРОЛОГА», «Начать заново» стартует с уровня 1.
- [ ] Партиклы: кровь при попадании, дым из ствола, вспышка выстрела.
- [ ] `?perftest`: `drawCalls` ≤ 200, `triangles` ≤ 800 000.
- [ ] Консоль без красных ошибок; в кат-сценах нет утечек геометрии (сцена очищается в `onEnd`).

## Известные ограничения

- Тени: CSM (2 каскада, `shadowMapSize: 1024`) с fallback на `PCFSoftShadowMap` — трассировка из `three-realtime-rt` недоступна в публичных CDN.
- Постобработка: SSAO + Bloom + OutputPass + FXAA; каждый пасс отключается URL-флагом.
- Кнопка «Начать службу» запускает полный поток: вступление → пробуждение → туториал → три уровня → финальная кат-сцена.
- Чекпоинт — начало текущего уровня; при смерти доступен респавн с чекпоинта (здоровье, броня и боезапас восстанавливаются из сохранения) или выход в меню.
- Для диагностики: `?play` — сразу на первый уровень, `?selftest` — автоматическая проверка оружия, врагов, смерти и урона с отчётом в консоль.
- Модели оружия от первого лица привязаны к камере; их положение подобрано под FOV 75.
- Единственный внешний ресурс — Three.js и шрифт Cinzel; оба грузятся с CDN. Без сети интерфейс откатывается на системный шрифт, но игра требует загрузки Three.js.
