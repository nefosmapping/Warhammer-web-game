# МЕХАНИКИ ИГРЫ: «Комиссар Вондер: Крушение над Армагеддоном»

**Формат файла:** `механики.txt`  
**Назначение:** техническое и геймдизайнерское описание всех систем игры, достаточное для генерации кода по промпту.

---

## 1. ЗАСТАВКА И ЗАПУСК ИГРЫ

### 1.1. Splash-экран «KrimProduction представляет»

При самом первом запуске (и при каждом старте игры, если не добавлен флаг `skipSplash`) показывается **плавно анимированная заставка**.

**Визуал:**
- Фон — **плавный фиолетовый градиент** (от тёмно-фиолетового `#1a0033` в центре к чёрному `#000000` по краям; либо диагональный градиент `#2b0a4a → #000000`).
- Поверх фона — **белая надпись** `KrimProduction представляет`, шрифт — строгий, крупный sans-serif (например, `Cinzel`, `Trajan Pro` или системный `Georgia` с letter-spacing).
- Лёгкое свечение вокруг текста (CSS `text-shadow`, мягкий фиолетовый ореол `0 0 20px rgba(180,120,255,0.6)`).

**Анимация (3–4 секунды):**
1. **0.0–0.8 с** — фон проявляется из чёрного, градиент «включается» (opacity 0 → 1).
2. **0.8–1.8 с** — надпись плавно проявляется (`opacity 0 → 1`) с лёгким увеличением (`scale 0.95 → 1.0`) и уменьшением `letter-spacing` (эффект «сборки» текста).
3. **1.8–3.0 с** — текст держится на экране, лёгкое мерцание/дыхание свечения (`text-shadow` пульсирует).
4. **3.0–3.8 с** — весь экран плавно уходит в чёрное (`opacity 1 → 0`), затем переключается на главное меню.

**Реализация:**
- Отдельный HTML-блок `#splash` поверх `canvas`, CSS-keyframes для каждой фазы, `setTimeout` для смены фазы.
- По клику или нажатию любой клавиши заставку можно **пропустить** — плавный fade-out за 0.4 с и переход к меню.
- Звук заставки опционален: тихий гул/нарастающий бас, но не обязателен.

### 1.2. Главное меню (после заставки)

- Тот же фиолетовый градиент, по центру — название игры: **«КОМИССАР ВОНДЕР»** и подзаголовок **«Крушение над Армагеддоном»**.
- Кнопки: **«Начать службу»** (старт), **«Настройки»** (громкость, чувствительность мыши, качество рендера), **«Выход»** (заглушка).
- Стиль кнопок: тёмно-фиолетовые панели с белой обводкой, при наведении — свечение.

### 1.3. Заставка-переходы между уровнями

Между кат-сценами и уровнями — **затемнение** (fade to black 0.5 с) с появлением названия уровня белым текстом на чёрном фоне (2 с), затем fade-in в игру.

## 4. ОРУЖИЕ

### 4.1. Болтер (основное)

- **Тип:** автоматическая винтовка, стреляет болтами (самонаводящиеся ракеты малого калибра).
- **Урон:** 25 за болт.
- **Скорострельность:** 600 выстрелов/мин (10 в секунду).
- **Магазин:** 30 патронов.
- **Перезарядка:** 2.0 с (`R`).
- **Разброс:** минимальный (точная стрельба), лёгкая отдача камеры вверх (2° за выстрел, плавно возвращается).
- **Эффект попадания:** вспышка на враге, лёгкий взрыв (искры + дым), звук глухого «THUMP».
- **Боезапас:** максимум 120 патронов (30 в магазине + 90 в резерве).
- **Модель от первого лица:** видна в правом нижнем углу, при выстреле дёргается вверх-назад, при перезарядке — анимация смены магазина (0.5 с подъём, 1.0 с смена, 0.5 с возврат).

### 4.2. Цепной меч (ближний бой)

- **Тип:** оружие ближнего боя, вращающаяся цепь.
- **Урон:** 60 за удар.
- **Дальность:** 2.0 м.
- **Скорость атаки:** 1 удар в 0.8 с.
- **Эффект:** при попадании — брызги крови, искры, звук ревущей цепи.
- **Модель от первого лица:** видна в правом нижнем углу, при атаке — замах справа-налево (0.4 с), рывок вперёд.
- **Особенность:** пока цепной меч активен, игрок может **отражать** атаки ближнего боя орков (шанс 50%), если нажать `ПКМ` за 0.3 с до удара (упрощённый парир).

### 4.3. Гранаты

- **Тип:** осколочные гранаты Имперской Гвардии.
- **Урон:** 120 в радиусе 4 м, падает до 40 на краю радиуса.
- **Количество:** стартово 2, максимум 4.
- **Бросок:** `G`, граната летит по дуге, взрыв через 2 с после броска.
- **Эффект:** вспышка, дым, осколки, звук взрыва, лёгкая тряска камеры.
- **Опасность для игрока:** да, граната наносит урон и игроку (дружественный огонь).

### 4.4. Переключение оружия

Слоты: `1` — болтер, `2` — цепной меч (или `ПКМ` для мгновенного удара мечом), `3` — граната (или `G` для мгновенного броска).

## 5. ПРОТИВНИКИ

### 5.1. Орк-бойз (основной)

| Параметр | Значение |
|---|---|
| Здоровье | 60 HP |
| Урон (ближний бой) | 15 за удар |
| Скорость | 4 м/с (медленнее игрока) |
| Дальность атаки | 1.5 м |
| Скорость атаки | 1 удар в 1.2 с |
| Поведение | Идёт к игроку по прямой, атакует топором. При получении урона — рычит, может замедлиться на 0.2 с |

**Модель:** низкий, широкий зелёный орк с топором. Простая low-poly модель (параллелепипеды + сфера-голова), анимация — покачивание при ходьбе, замах топором при атаке.

### 5.2. Орк-стрелок

| Параметр | Значение |
|---|---|
| Здоровье | 40 HP |
| Урон (выстрел) | 10 за попадание |
| Скорость | 3 м/с |
| Дальность атаки | 15 м |
| Скорость стрельбы | 1 выстрел в 1.5 с, очередями по 3 |
| Поведение | Держит дистанцию, стреляет из «шутты», при приближении игрока — отходит назад |

**Модель:** орк с грубым оружием, ствол которого светится при выстреле. Трассеры — жёлтые линии.

### 5.3. Орочий ноб (мини-босс, уровень 2)

| Параметр | Значение |
|---|---|
| Здоровье | 300 HP |
| Урон (ближний бой) | 30 за удар |
| Скорость | 3.5 м/с |
| Дальность атаки | 2.5 м |
| Скорость атаки | 1 удар в 1.8 с |
| Поведение | Идёт к игроку, при 50% HP — ускоряется (ярость), рычит громче |

**Модель:** увеличенный орк (в 1.5 раза), с усиленным топором и наплечниками.

### 5.4. Общая логика ИИ

- **Состояния:** `idle` → `chase` (если игрок в радиусе 20 м) → `attack` (если в радиусе атаки) → `dead`.
- **Обнаружение:** по прямой видимости (raycast) или по шуму (выстрел игрока привлекает орков в радиусе 15 м).
- **Урон от попаданий:** при получении урона орк кратко «вздрагивает» (0.2 с), затем продолжает.
- **Смерть:** анимация падения (0.5 с), затем труп исчезает через 5 с.

## 6. УРОВНИ: СТРУКТУРА И ОРИЕНТИРЫ

Каждый уровень — **отдельная сцена Three.js**, загружаемая при переходе. Загрузка сопровождается экраном с названием уровня.

### 6.1. Уровень 1 — «Джунгли смерти»

- **Размер:** ~80×80 м.
- **Ландшафт:** плоская земля с неровностями, деревья (простые цилиндры + сферы), обломки «Валькирии» (разбросанные кубы и плоскости), орочьи тотемы.
- **Освещение:** тусклый дневной свет (зелёно-жёлтый), дым, туман.
- **Триггеры:**
  - Триггер 1 (начало): вокс-сообщение от сержанта.
  - Триггер 2 (середина): аптечка + ящик патронов.
  - Триггер 3 (мост): спавн 2 орков.
  - Триггер 4 (конец): переход на уровень 2.
- **Враги:** 5 орков-бойзов, 2 стрелка (спавнятся по триггерам).
- **Чекпоинт:** при входе на мост.

### 6.2. Уровень 2 — «Орочья выработка»

- **Размер:** ~60×60 м, но с коридорами и перепадами высот.
- **Ландшафт:** туннели (коробки-стены), открытая площадка с генератором (цилиндр), подъём на поверхность в конце.
- **Освещение:** тусклые лампы, искры, красноватый свет.
- **Триггеры:**
  - Триггер 1 (вход): спавн 2 орков из-за угла.
  - Триггер 2 (генератор): спавн 2 стрелков на возвышенности.
  - Триггер 3 (арена): спавн ноба + 2 орков.
- **Враги:** 6 орков-бойзов, 2 стрелка, 1 ноб.
- **Чекпоинт:** при входе на арену с нобом.

### 6.3. Уровень 3 — «Последний рывок»

- **Размер:** ~100×60 м (открытое поле).
- **Ландшафт:** воронки, обломки техники, мешки с песком у штаба, флаги.
- **Освещение:** багровое небо, дым, прожекторы у штаба.
- **Триггеры:**
  - Триггер 1 (выход на поле): волна 1 — 3 орка.
  - Триггер 2 (середина поля): волна 2 — 3 орка + 2 стрелка.
  - Триггер 3 (у ворот): финальная волна — 2 орка.
  - Триггер 4 (ворота): открываются, вход в штаб → финальная кат-сцена.
- **Враги:** 8 орков-бойзов, 3 стрелка.
- **Чекпоинт:** при входе на поле и перед финальной волной.

## 7. ДИАЛОГОВАЯ СИСТЕМА

### 7.1. Диалоговое окно

- HTML-оверлей поверх canvas, в нижней трети экрана.
- Полупрозрачная тёмная панель с белой рамкой, стиль — «имперский» (строгий шрифт, аквила в углу).
- **Спикер** отображается над текстом: например, `[Сержант Колл]`, `[Гарик Вондер]`, `[Вокс-связь]`.
- Текст появляется **посимвольно** (typewriter-эффект, 30 мс на символ).
- **Пропуск:** `Пробел` — либо мгновенно показывает весь текст, либо (при повторном нажатии) закрывает диалог.
- **Автозакрытие:** через 4 с после окончания печати, если игрок не нажал ничего (для необязательных реплик).

### 7.2. События диалогов

- Диалоги запускаются **триггерами** (по координатам, по времени, по событию — например, после убийства врага).
- Кат-сцены используют ту же систему, но с фиксированной камерой и отключённым управлением.

---

## 8. КАТ-СЦЕНЫ

### 8.1. Реализация

- Кат-сцена — это **массив ключевых кадров камеры** (`position`, `lookAt`, `duration`) и **таймлайн событий** (диалоги, звуки, включение/выключение объектов).
- Во время кат-сцены управление игроком отключено (`pointerLock` снят, клавиши игнорируются, кроме `Пробел` для пропуска).
- Камера движется по ключевым кадрам с **плавной интерполяцией** (lerp/easing).
- Пропуск кат-сцены (`Пробел`) — мгновенный переход к следующему состоянию игры (начало уровня или меню).

### 8.2. Список кат-сцен

| № | Название | Длительность | Тип |
|---|---|---|---|
| 1 | Полёт «Валькирии» | ~40 с | Внешняя камера + вид от первого лица |
| 2 | Крушение | ~10 с | Тряска, вспышки, затемнение |
| 3 | Пробуждение в обломках | ~15 с | От первого лица + туториал |
| 4 | Финал в штабе | ~30 с | От первого лица + общий план |

## 9. HUD (интерфейс игрока)

В левом нижнем углу:
- **Здоровье:** `100` (красная иконка сердца/аквилы), полоса HP.
- **Броня:** `50` (синяя иконка), полоса AP.

В правом нижнем углу:
- **Боезапас:** `30 / 90` (в магазине / в резерве).
- **Гранаты:** иконка + количество `2`.

По центру:
- **Прицел:** маленькая белая точка или крестик.

Сверху по центру (появляется на 3 с при смене задачи):
- **Текущая цель:** «Добраться до моста», «Зачистить выработку», «Пробиться к штабу».

## 10. ЗВУК

- **Фоновая музыка:** опционально, мрачный эмбиент с низкими басами (можно заглушку).
- **Звуки оружия:** болтер (глухие выстрелы), цепной меч (рев), граната (взрыв).
- **Звуки врагов:** рычание орков, «ВОАГХ!», «ДАКА-ДАКА!».
- **Звуки окружения:** ветер, стрельба вдалеке, гул «Валькирии», пожар.
- **Звук HUD:** тихий щелчок при подборе предмета, при перезарядке.

**Реализация:** Web Audio API или `<audio>`-элементы. Все звуки — **заглушки** (сгенерированные или пустые), чтобы не требовать внешних файлов. При отсутствии аудиофайлов игра работает без ошибок.

## 11. ТЕХНИЧЕСКИЕ ЗАМЕТКИ ДЛЯ РЕАЛИЗАЦИИ

### 11.1. Стек

- **Three.js** (CDN, например `https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js` или ES-модуль с unpkg).
- **HTML5 + CSS3** для меню, заставки, HUD и диалогов.
- **Vanilla JS** (без сборщиков), весь код — в одном или нескольких `<script>`-тегах.

### 11.2. Структура файлов

```
index.html
style.css
game.js
levels.js (опционально)
```

Или **всё в одном `index.html`** — для простоты вайбкодинга.

### 11.3. Физика

- **Без физического движка.** Простая коллизия: игрок — капсула (радиус 0.4), стены — AABB-боксы (проверка пересечения).
- **Гравитация:** только для гранат (бросок по параболе, упрощённо).
- **Прыжок:** не реализуется (игрок ходит по земле).

### 11.4. Рендер

- **Камера:** `PerspectiveCamera`, FOV 75°, near 0.1, far 200.
- **Освещение:** `AmbientLight` (тусклый) + `DirectionalLight` (основной) + опционально точечные источники (костры).
- **Туман:** `FogExp2` или `Fog` для атмосферы.
- **Модели:** примитивы (боксы, цилиндры, сферы) с простыми материалами `MeshStandardMaterial` или `MeshLambertMaterial` — без внешних `.glb`/`.obj` файлов, чтобы игра работала сразу.

### 11.5. Производительность

- Целевой FPS: 60.
- Ограничение: не более ~20 врагов одновременно на сцене.
- Уровни небольшие, чтобы не грузить браузер.

### 11.6. Сохранение прогресса

- **Чекпоинты:** в `localStorage` сохраняется текущий уровень и позиция чекпоинта.
- При смерти — кнопка «Повторить с чекпоинта» загружает сохранение.
